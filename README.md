# 💸 MisTickets: Controla tus Gastos con Fotos

## 📝 Descripción del Proyecto

**MisTickets** es una aplicación móvil desarrollada con **Flutter** que simplifica la gestión de gastos personales. Su objetivo principal es ofrecer a los usuarios una herramienta rápida y visual para registrar cada gasto mediante la captura o subida de una foto del ticket (comprobante de compra).

Ideal para el seguimiento presupuestario diario, MisTickets te permite clasificar tus gastos y obtener un resumen claro de tu actividad financiera.

---

## ✨ Características Clave

MisTickets ofrece una solución intuitiva para el control de gastos:

* **Registro Fotográfico:** Sube o toma una foto del ticket para asociarla directamente al gasto.
* **Detalle Completo:** Cada registro incluye el monto, una categoría (alimentos, transporte, ocio, etc.) y la fecha del gasto.
* **Estadísticas Rápidas:**
    * **Total Gastado:** Visualiza la suma de todos los montos registrados.
    * **Conteo de Tickets:** Conoce rápidamente cuántos comprobantes has ingresado.
* **Filtros por Fecha:** Permite visualizar los gastos en rangos de tiempo específicos.
* **Interfaz Amigable:** Diseño limpio y responsivo gracias a Flutter.

## 🚀 Instalación y Ejecución Local

Para configurar y ejecutar **MisTickets** en tu entorno de desarrollo, sigue los siguientes pasos.

### Prerrequisitos

* Tener instalado [Flutter SDK](https://flutter.dev/docs/get-started/install).
* Configurar un IDE (Visual Studio Code o Android Studio).

### Pasos

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://docs.github.com/es/repositories/creating-and-managing-repositories/quickstart-for-repositories](https://docs.github.com/es/repositories/creating-and-managing-repositories/quickstart-for-repositories)
    cd MisTickets
    ```

2.  **Instalar dependencias:**
    ```bash
    flutter pub get
    ```

3.  **Ejecutar la aplicación:**
    Asegúrate de tener un emulador o dispositivo físico conectado.
    ```bash
    flutter run
    ```
    *(Para una plataforma específica, puedes usar `flutter run --release` para rendimiento o `flutter run -d chrome` si también soporta web.)*
